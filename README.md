## King Of The Tale
### Description:

          King Of The Hill (Arma 3 Sa-Matra mod) based mod to **Hytale**. The main objective of this gamemode (and this mod) is **area domination**, by 1 or more teams fighting against each other, trying to have as many player for each team in the area as possible. The team with **most players** in the area will be able to mark points. The **first team** to reach **100 points** wins the match.

I created this mod because I am really addicted to this gamemode, and I'm trying to get experience in **Hytale Modding**.



## About the mod:

          To start playing with the mod, you must create (or load) an Hytale World with this Mod loaded, while in the World (in-game), you must use **/KOTT GUI**, this command will open an UI interface to you configurate the KOTT Match Settings, after settings your options, click in the Start Button to start the match.
