# **King Of The** <span style="color: #e03e2d;"><strong>Tale</strong></span>  <span style="color: #ced4d9;"><strong>(W.I.P.)</strong></span>

 

### <span style="color: #fff;"><strong>Description</strong></span>

<p style="padding-left: 40px;"><span style="color: #ced4d9;">Fight against other players, or in zone spawning NPCs, stay inside the Main Zone to mark points for your Team, kill other Players/NPCs, make money (you will need for buying new tools/weapons/gears) and most important thing: work with your team (or not if you are a lonewolf &gt;:-D)</span></p><p style="padding-left: 40px;"><span style="color: #f1c40f;">To start playing with the mod, you must create (or load) an Hytale World with this Mod loaded, while in the World (in-game), you must use&nbsp;<span style="color: #ba372a;">/op self <span style="color: #f1c40f;">to be able to use commands, and use</span></span>&nbsp;<span style="color: #e03e2d;">/kott gui<span style="color: #f1c40f;">.</span></span> This command will open an UI interface to you configure the KOTT Match settings. When ready, click in the Start button to start the match.</span></p> 

### <span style="color: #fff;"><strong>About the mod</strong></span>

<p style="padding-left: 40px;"><span style="color: #ced4d9;">King Of The Hill (Arma 3 Sa-Matra mod) based mod, to Hytale. The main objective of this gamemode (and this mod) is area domination, by 1 or more teams fighting against each other, trying to have as many player for each team in the area as possible. The team with most players in the area will be able to mark points. The first team to reach 100 points wins the match. The goal is simple: kill enemy, make money and mark point.</span></p><p style="padding-left: 40px;"><span style="color: #ced4d9;">I created this mod because I am really addicted to this gamemode, and I'm trying to get experience in Hytale Modding.</span></p>
